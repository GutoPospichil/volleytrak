# VolleyTrak 0.3.0 beta

Foco: geração automática de clipes com feedback humano.

## Download

### Portable
Baixe todas as partes `VolleyTrakPortable.7z.001` e `.002` para a mesma pasta e extraia a `.001` com 7-Zip.

### Instalador
Baixe todas as partes `VolleyTrakSetup.7z.001` e `.002` para a mesma pasta, extraia a `.001` e execute `VolleyTrakSetup.exe`.

## O que está incluído

- Python, PyTorch CUDA, YOLO, D-FINE, VballNet e ffmpeg
- Perfil de feedback e ranker aprendidos
- Geração clip-only: VballNet, áudio, contatos, rallies e cortes
- Revisão com salvar, excluir com motivo, estrela e highlight
- Horário do clipe clicável para o vídeo original
- Sem vídeo anotado

## Requisitos

- Windows 10/11 64-bit
- Driver NVIDIA atualizado
- 7-Zip para juntar as partes
- Cerca de 8 GB livres

## Aviso

Instalador não assinado; o Windows pode mostrar SmartScreen. O aplicativo é de teste.
